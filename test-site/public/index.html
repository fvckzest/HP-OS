Terms and boundaries
Unavailable
The required API capability is not implemented.
Blocked
Required configuration, implementation, environment or approval is missing.
Not run
A runnable scenario has not been explicitly started in this profile.
Passed / failed
The scenario's stated checks passed or failed. This does not complete a ticket or release gate.
Interrupted
The run stopped or awaits a buyer/operator step.
Unknown outcome
A request may have committed without a readable response. Resume the saved run to retain its original action identities.
Reservation
A temporary capacity hold while an Order is unpaid or payment is unresolved.
Dispatch / delivery
A provider accepting an email send and independently confirming delivery are separate facts.
